# terobit pack file - .tbpk

contains tbres, tbwas, tbman in a gzipped style directory.

there is only one version, therefore there is no futher documentation.

the type is simply .tar.gz renamed.

# special

it can also be simply a directory for development testing when file size does not matter. in production there should only ever be a file, gzipped. directories are not unzipped as they are not a file.
