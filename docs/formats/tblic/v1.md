# terobit license - .tblic - v1

[common header](../common/HEADER.md) with magic `TBLC`, version `1`, then this body
encoded with postcard (see [conventions](../common/CONVENTIONS.md#body-encoding)).

## body

```rust
struct LicenseV1 {
    /// the user who owns the realm
    user_id: u64,
    /// the realm they own
    realm_id: u64,
    /// the key that made `signature`. purpose must be License
    cert: Certificate,
    /// ed25519 by cert.public_key over hash(LICENSE, terms)
    signature: [u8; 64],
}
```

`terms` is 16 fixed bytes: `user_id` then `realm_id`, each as a little endian `u64`. this
fixed form is rebuilt from the decoded fields, so there is exactly one way to produce it.

`Certificate` and `hash` are defined in [integrity](../common/INTEGRITY.md).

## verifying

1. check `cert` as described in [integrity](../common/INTEGRITY.md#certificates), expecting
   purpose `License`
2. verify `signature` with `cert.public_key` over `hash(LICENSE, terms)`
3. `user_id` must be the last logged in user and `realm_id` the realm being started

the algorithm is fixed to ed25519 in v1. a new algorithm means a new version.
