# terobit signature - .tbsig - v1

[common header](../common/HEADER.md) with magic `TBSG`, version `1`, then this body
encoded with postcard (see [conventions](../common/CONVENTIONS.md#body-encoding)).

## body

```rust
struct SignatureV1 {
    key_kind: KeyKind,
    /// first 8 bytes of blake3(public key), so the reader can pick the right key
    /// when keys are rotated. not a security check by itself.
    key_id: [u8; 8],
    /// ed25519 signature over the exact bytes of manifest.tbman, header included
    signature: [u8; 64],
}

enum KeyKind {
    Platform = 0,
}
```

the algorithm is fixed to ed25519 in v1. a new algorithm means a new version.

## verifying

1. read the header and body
2. find the trusted key whose `key_id` matches. none: reject
3. verify `signature` against the raw bytes of `manifest.tbman` as stored in the pack.
   never re-encode the manifest before checking
4. only after this passes, decode the manifest

a client and a server keep separate trusted key lists, see
[integrity](../common/INTEGRITY.md#who-signs).
