# terobit signature - .tbsig - v1

[common header](../common/HEADER.md) with magic `TBSG`, version `1`, then this body
encoded with postcard (see [conventions](../common/CONVENTIONS.md#body-encoding)).

## body

```rust
struct SignatureV1 {
    /// the key that made `signature`. purpose must be Pack
    cert: Certificate,
    /// ed25519 by cert.public_key over hash(PACK, manifest bytes)
    signature: [u8; 64],
}
```

`Certificate` and `hash` are defined in [integrity](../common/INTEGRITY.md).

## verifying

1. check `cert` as described in [integrity](../common/INTEGRITY.md#certificates), expecting
   purpose `Pack`
2. verify `signature` with `cert.public_key` over `hash(PACK, bytes)`, where bytes are the
   whole `manifest.tbman` exactly as stored, header included. never re-encode the manifest
   first
3. only after this passes, decode the manifest

the algorithm is fixed to ed25519 in v1. a new algorithm means a new version.
